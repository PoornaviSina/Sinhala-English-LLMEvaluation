# Response Quality Evaluation Rubric

## Purpose

This rubric evaluates the quality of the customer-support responses
generated by the LLM independently from intent-classification accuracy.

Each response is evaluated using four dimensions:

1. Relevance
2. Helpfulness
3. Language Appropriateness
4. Unsupported Claims

---

## 1. Relevance

Measures whether the generated response directly addresses the
customer's message and identified support need.

### Score 2 — Fully Relevant
The response clearly addresses the customer's issue or request.

### Score 1 — Partially Relevant
The response relates to the issue but is incomplete, vague, or
does not fully address the customer's need.

### Score 0 — Not Relevant
The response does not meaningfully address the customer's issue.

---

## 2. Helpfulness

Measures whether the response provides useful and appropriate
guidance or a reasonable next step.

### Score 2 — Helpful
The response provides an appropriate answer, instruction, request
for necessary information, or useful next step.

### Score 1 — Partially Helpful
The response provides some useful information but lacks sufficient
guidance or clarity.

### Score 0 — Not Helpful
The response provides no useful guidance or gives inappropriate
guidance.

---

## 3. Language Appropriateness

Measures whether the response is understandable and linguistically
appropriate for the customer's message.

### Score 2 — Appropriate
The response is clear, understandable, and suitable for the
customer's language context.

### Score 1 — Partially Appropriate
The response is understandable but contains awkward wording,
unnecessary language switching, or minor language problems.

### Score 0 — Inappropriate
The response is difficult to understand or unsuitable for the
customer's language context.

---

## 4. Unsupported Claim

Measures whether the assistant claims knowledge or actions that
cannot be supported by the information available in the customer's
message.

### False — No Unsupported Claim
The response does not invent unavailable information and does not
claim that an action has been completed without evidence.

### True — Unsupported Claim Present
The response invents information or falsely implies access to
external business systems or completed actions.

Examples include:

- claiming that an order has been checked when no order system is
  connected;
- claiming that a refund has been processed;
- claiming that a payment has been verified;
- claiming that a delivery date or parcel location is known without
  supporting information;
- claiming that a product is currently in stock without inventory
  information;
- claiming that an account has been modified.

---

## Quality Score

The three scored dimensions produce a maximum score of:

Relevance + Helpfulness + Language Appropriateness

2 + 2 + 2 = 6 points per response.

Unsupported claims are reported separately because they represent
a specific reliability and hallucination risk.

Maximum quality score per response: 6.
